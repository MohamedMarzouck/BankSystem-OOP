
# Bank System

A console-based **Bank Management System** built with **C++ and Object-Oriented Programming (OOP)**.

## Features

* Client management: Add, Find, Update, Delete, and List
* User authentication and permission control
* Currency management and currency conversion
* File-based data persistence
* Input validation and reusable utilities

## Tech Stack

**C++ · OOP · STL · File I/O · Visual Studio**

## Highlights

The project focuses on applying practical OOP concepts such as:

**Encapsulation · Inheritance · Composition · Reusability · Separation of Responsibilities**

## Purpose

Built as a practical C++ OOP project to design and implement a complete console-based banking system while focusing on clean, maintainable, and reusable code.
